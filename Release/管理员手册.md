# ChiefMusic 授权管理员操作手册

## 生成授权码

### 方法 1：使用数据库直接插入
```bash
# SSH 登录服务器
ssh root@YOUR_SERVER_IP

# 进入 SQLite
sqlite3 /www/mdskill-license/data/licenses.db

# 插入授权码
INSERT INTO licenses (
  license_key, 
  user_id, 
  max_devices, 
  expires_at, 
  app_name
) VALUES (
  'CHIEF-XXXXX-XXXXX-XXXXX-XXXXX',  -- 授权码（自定义）
  'UserName-DeviceID',               -- 用户标识
  2,                                  -- 最多绑定设备数
  '2027-06-03',                      -- 过期日期
  'ChiefMusic'                       -- 应用名称（必须是 ChiefMusic）
);

# 验证插入成功
SELECT * FROM licenses WHERE app_name = 'ChiefMusic';

# 退出
.exit
```

### 方法 2：使用授权码生成工具（推荐）
```bash
# 在服务器上创建生成脚本
cat > /www/mdskill-license/generate_chiefmusic_license.sh << 'EOF'
#!/bin/bash

if [ -z "$1" ]; then
  echo "用法: $0 设备码 [有效期天数]"
  echo "示例: $0 CB728197FBFA10DD 365"
  exit 1
fi

DEVICE_ID=$1
DAYS=${2:-365}
EXPIRES_AT=$(date -d "+${DAYS} days" +%Y-%m-%d)
LICENSE_KEY="CHIEF-$(openssl rand -hex 2 | tr '[:lower:]' '[:upper:]')-$(openssl rand -hex 2 | tr '[:lower:]' '[:upper:]')-$(openssl rand -hex 2 | tr '[:lower:]' '[:upper:]')-$(openssl rand -hex 3 | tr '[:lower:]' '[:upper:]')"
USER_ID="User-${DEVICE_ID}"

sqlite3 /www/mdskill-license/data/licenses.db << SQL
INSERT INTO licenses (license_key, user_id, max_devices, expires_at, app_name)
VALUES ('${LICENSE_KEY}', '${USER_ID}', 2, '${EXPIRES_AT}', 'ChiefMusic');
SQL

echo "✅ 授权码生成成功！"
echo ""
echo "授权码: ${LICENSE_KEY}"
echo "用户ID: ${USER_ID}"
echo "过期时间: ${EXPIRES_AT}"
echo "最大设备数: 2"
EOF

chmod +x /www/mdskill-license/generate_chiefmusic_license.sh

# 使用示例
/www/mdskill-license/generate_chiefmusic_license.sh CB728197FBFA10DD 365
```

## 查询授权信息

### 查看所有 ChiefMusic 授权码
```bash
ssh root@YOUR_SERVER_IP
sqlite3 /www/mdskill-license/data/licenses.db

SELECT 
  license_key,
  user_id,
  max_devices,
  expires_at,
  is_active,
  created_at
FROM licenses 
WHERE app_name = 'ChiefMusic'
ORDER BY created_at DESC;
```

### 查看特定授权码的设备绑定情况
```bash
sqlite3 /www/mdskill-license/data/licenses.db

SELECT 
  d.device_id_hash,
  d.device_info,
  d.activated_at,
  d.last_verified_at,
  d.is_active
FROM devices d
JOIN licenses l ON d.license_id = l.id
WHERE l.license_key = 'CHIEF-XXXXX-XXXXX-XXXXX-XXXXX'
  AND l.app_name = 'ChiefMusic';
```

## 授权管理操作

### 禁用授权码
```bash
sqlite3 /www/mdskill-license/data/licenses.db

UPDATE licenses 
SET is_active = 0 
WHERE license_key = 'CHIEF-XXXXX-XXXXX-XXXXX-XXXXX'
  AND app_name = 'ChiefMusic';
```

### 启用授权码
```bash
sqlite3 /www/mdskill-license/data/licenses.db

UPDATE licenses 
SET is_active = 1 
WHERE license_key = 'CHIEF-XXXXX-XXXXX-XXXXX-XXXXX'
  AND app_name = 'ChiefMusic';
```

### 解绑设备
```bash
# 查看设备列表
sqlite3 /www/mdskill-license/data/licenses.db "
SELECT 
  d.id,
  d.device_info,
  d.activated_at
FROM devices d
JOIN licenses l ON d.license_id = l.id
WHERE l.license_key = 'CHIEF-XXXXX-XXXXX-XXXXX-XXXXX'
  AND l.app_name = 'ChiefMusic';
"

# 解绑特定设备
sqlite3 /www/mdskill-license/data/licenses.db "
DELETE FROM devices WHERE id = <设备ID>;
"
```

### 延长授权期限
```bash
sqlite3 /www/mdskill-license/data/licenses.db

UPDATE licenses 
SET expires_at = '2028-06-03' 
WHERE license_key = 'CHIEF-XXXXX-XXXXX-XXXXX-XXXXX'
  AND app_name = 'ChiefMusic';
```

### 查看数据库统计
```bash
sqlite3 /www/mdskill-license/data/licenses.db << SQL
-- ChiefMusic 授权码总数
SELECT COUNT(*) as total_licenses 
FROM licenses 
WHERE app_name = 'ChiefMusic';

-- 激活的授权码数
SELECT COUNT(*) as active_licenses 
FROM licenses 
WHERE app_name = 'ChiefMusic' 
  AND is_active = 1;

-- 已过期的授权码数
SELECT COUNT(*) as expired_licenses 
FROM licenses 
WHERE app_name = 'ChiefMusic' 
  AND date(expires_at) < date('now');

-- 设备绑定总数
SELECT COUNT(*) as total_devices
FROM devices d
JOIN licenses l ON d.license_id = l.id
WHERE l.app_name = 'ChiefMusic'
  AND d.is_active = 1;
SQL
```

## 常见问题处理

### 用户反馈：激活失败
1. 检查授权码是否存在且未过期
2. 检查授权码是否被禁用
3. 检查设备数是否已满
4. 查看服务器日志排查错误

### 用户需要更换设备
1. 查看当前绑定的设备
2. 解绑旧设备
3. 用户在新设备上重新激活

### 批量生成授权码
```bash
# 生成 10 个授权码
for i in {1..10}; do
  /www/mdskill-license/generate_chiefmusic_license.sh BATCH-$i 365
done
```
