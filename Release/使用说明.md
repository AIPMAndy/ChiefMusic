# ChiefMusic 安装与使用说明

## 系统要求
- macOS 14.0 或更高版本
- 需要网络连接进行激活

## 安装步骤

### 1. 安装应用
1. 双击 `ChiefMusic-v1.0.dmg` 打开安装包
2. 将 `ChiefMusic.app` 拖拽到「应用程序」文件夹
3. 首次启动时，如果遇到「无法打开，因为来自身份不明的开发者」提示：
   - 打开「系统设置」→「隐私与安全性」
   - 找到 ChiefMusic 的提示，点击「仍要打开」
   - 或在终端执行：`xattr -cr /Applications/ChiefMusic.app`

### 2. 获取设备码
1. 启动 ChiefMusic
2. 在激活界面会显示您的设备码（16位字符）
3. 复制设备码并提供给管理员

### 3. 激活应用
1. 从管理员处获取授权码（格式：CHIEF-XXXXX-XXXXX-XXXXX-XXXXX）
2. 在激活界面粘贴授权码
3. 点击「激活」按钮
4. 激活成功后即可正常使用

## 授权说明

### 授权类型
- **按年订阅**：¥199/年，推荐
- **按月订阅**：¥29/月

### 授权特性
- 每个授权码最多绑定 2 台设备
- 支持在线验证 + 5 天离线容错
- 授权有效期：1 年（从激活日期开始计算）

### 离线使用
- 激活后，即使断网也可继续使用 5 天
- 超过 5 天未联网验证，需要重新联网激活
- 建议每周至少联网一次以保持授权有效

## 常见问题

### Q1: 激活失败，提示「激活失败，请检查授权码或网络连接」
**解决方案**：
1. 检查授权码是否完整复制（应包含 4 个短横线）
2. 确认网络连接正常
3. 检查授权码是否已过期或达到设备数上限
4. 联系管理员获取新的授权码

### Q2: 激活失败，提示「授权码不存在」
**解决方案**：
- 确认授权码拼写正确
- 联系管理员确认授权码是否已生成

### Q3: 激活失败，提示「设备数已达上限」
**解决方案**：
- 每个授权码最多绑定 2 台设备
- 如需更换设备，请联系管理员解绑旧设备

### Q4: 试用期已过期
**解决方案**：
- ChiefMusic 提供试用期体验
- 试用期结束后需要输入授权码激活
- 联系管理员购买授权

### Q5: Logo 图标未更新
**解决方案**：
```bash
# 在终端执行以下命令清理图标缓存
sudo rm -rf /Library/Caches/com.apple.iconservices.store
killall Finder
killall Dock
```
然后重启 Mac。
